# 📖 Présentation

Ce projet est mon portfolio personnel, conçu pour présenter mon parcours, mes compétences et les projets que j'ai réalisés dans le domaine du développement web et mobile.

Il met l'accent sur une interface moderne, des animations fluides et une navigation intuitive afin d'offrir une expérience utilisateur agréable.

# 🚀 Installation

### Cloner le dépôt

```bash
git clone https://github.com/didier-lobognon/MonPortfolio.git
```

### Installer les dépendances

```bash
npm install
```

### Lancer le projet

```bash
npm run dev
```

L'application sera disponible sur :

```
http://localhost:5173
```
